Reading the list

  • Game version means the installed game update, not the emulator version. Where versions are listed, other versions are rejected by the handler.
  • No version check means the handler does not inspect that value. It does not mean all updates have been tested.
  • Historical rating preserves the old compatibility site's assessment. These ratings are not fresh tests, and several predate substantial fixes.
  • Source-only changes are present in the reviewed code but are newer than {{ compatibility.release }}. The download button links to the latest published release.

Help improve this list

If a listed game behaves differently, open an issue with the game serial and update version, emulator and KAMI versions, and the level or camera mode involved. Mention whether you used a release or built from source. These details make reports useful without guessing which edition was tested.
