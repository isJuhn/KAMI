# KAMI

Kot and Mouse Injector adds mouse control to selected emulated games in RPCS3 and PCSX2. It runs on Windows and uses PINE to communicate with the emulator.

[Download the latest release](https://github.com/isJuhn/KAMI/releases/latest) · [Website](https://isjuhn.github.io/KAMI/)

## Get started

Follow the [quickstart](https://isjuhn.github.io/KAMI/quickstart/) for runtime requirements, IPC setup, controls and troubleshooting. Check the [compatibility list](https://isjuhn.github.io/KAMI/compatibility/) for supported title IDs, game versions and known limitations.

The website replaces the separate MkDocs compatibility site. Its content lives alongside the application in [`docs/`](docs/README.md).

## Build and contribute

See the [developer guide](https://isjuhn.github.io/KAMI/developers/) for build prerequisites, native dependencies, source layout and contribution guidance. The repository's build scripts and CI workflow remain the reference for build commands.

To change the website, read [`docs/README.md`](docs/README.md) for local preview, validation and maintenance responsibilities. No AI service is required to edit or build it.
